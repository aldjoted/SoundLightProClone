# Mega Menu Background Image

## Required Image
Save your SoundLightPro background image as:
- **Filename:** `soundlightpro-background.jpg`
- **Location:** This directory (`frontend/public/images/MegaMenu/`)
- **Recommended dimensions:** 1920x810px (21:9 aspect ratio)
- **File size:** Under 200KB (optimized)

## Image Specifications
- **Format:** JPEG (or WebP for better performance)
- **Quality:** 80-85% (balance between quality and file size)
- **Content:** The dark professional equipment setup with SoundLightPro branding

The CSS is already configured to display this image with:
- Dark overlay (88-92% opacity) for text readability
- Cover sizing for responsive behavior
- Center positioning for optimal display
- Backdrop blur effects on menu items

## Current Implementation
The mega menu will automatically use this image once it's saved in this directory.
